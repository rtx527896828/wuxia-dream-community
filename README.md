# 武侠梦 · 玩家社区

「武侠梦」是一款在浏览器里玩的武侠动作 RPG：俯视角、快节奏清怪、随机掉落驱动的构筑。不用下载，打开网页就能玩。

这个仓库不放游戏代码，只做两件事：

- **收集问题和建议**：遇到 bug、卡关、数值不对劲，或者有想法，在 [Issues](../../issues/new/choose) 里开一条。
- **发布更新**：每次上线了什么，记在 [更新日志](CHANGELOG.md) 和 [Releases](../../releases) 里。点右上角的 Watch → Custom → Releases 就能收到通知。

## 报 bug 的时候

最有用的是游戏自己导出的**报告文件**：标题画面的「存档管理」里、或者暂停菜单里点「导出存档和日志」，会下载一个 `wuxia-report-….json` 文件，里面有存档、出错日志和你的浏览器信息，我们能照着把那一刻重放出来。开 issue 时把它拖进去就行。

不方便导出的话，写清楚这几样也很好：在哪一关、做了什么、看到了什么、本来以为会怎样，再加一张截图。
